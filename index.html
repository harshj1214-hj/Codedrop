This copy of Codedrop isn’t connected to storage yet. Whoever set it up needs to add the Supabase project URL and key at the top of index.html (see README.md).

Turn a file into a 12-character code. Whoever opens this page and types the code gets the file on their phone. No account needed.

Codes made on this phone

    How it works

    The file is encrypted on your phone with AES-256-GCM before it’s uploaded. The key is derived from the code (PBKDF2, 250,000 rounds) and the code is never uploaded, so the storage only holds scrambled data. The first four characters find the file; the last eight unlock it.

    Files can be up to 25 MB. Share codes privately: anyone who has one can open the file until it expires. Expired files are cleared out automatically.

    Type the code the sender gave you. The file is unlocked on this phone and downloaded to it.
